SOBRE

GROOVE MANAGER

Sistema Full-Stack para gerir o catálogo e o stock de uma loja de discos de vinil.

OBJETIVO

O objetivo é permitir a consulta, criação, edição e eliminação de produtos, mantendo as quantidades disponíveis guardadas numa base de dados.

COMO FUNCIONA

Depois do login, o utilizador pode pesquisar produtos, filtrar categorias, adicionar novos discos e registar entradas ou saídas de stock.

Todas as alterações são enviadas ao backend através de pedidos HTTP e ficam guardadas no MySQL.

TECNOLOGIAS

O frontend utiliza HTML, CSS e JavaScript. O backend utiliza Node.js e Express. Os produtos, as categorias e os utilizadores são guardados no MySQL.

SEGURANÇA

A página de stock e as operações que alteram produtos exigem uma sessão válida. As palavras-passe são guardadas através de hash com bcrypt.
